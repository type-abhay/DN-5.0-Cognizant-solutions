=== EXERCISE 2: E-COMMERCE SEARCH FUNCTION ===

1. Linear Search Execution:
Found: Product{ID=108, Name='Running Shoes', Category='Apparel'}

2. Binary Search Execution:
Found: Product{ID=108, Name='Running Shoes', Category='Apparel'}

--- Theoretical Analysis ---
Linear Search Complexity:
 - Best Case: O(1) [Item is at the first index]
 - Worst / Average Case: O(n) [Must scan through array]

Binary Search Complexity:
 - Best Case: O(1) [Item is at middle]
 - Worst / Average Case: O(log n) [Divides search space in half each step]

Platform Recommendation:
 - Binary search is significantly better for large e-commerce platforms with thousands or millions of products.
 - Tradeoff: Array must remain sorted. If product updates/inserts are frequent, balanced trees or search engines (e.g., Elasticsearch) are preferred.
